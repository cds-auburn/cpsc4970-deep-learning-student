# CPSC4970: Deep Learning Sample code

This repository contains code displayed during lecture demos.

Each module folder holds that module's notebooks and scripts, named by lecture
number. A demonstration that needs more than one file has its own folder, such
as `Module02/030_Iris_inference/`, with everything in it: the notebook, a
standalone script, helper modules, model files, data files and a README.

Paths in the lecture slides, such as `test.csv`, are relative to the
demonstration's folder. Open the notebook, or run the scripts, from there.
Downloaded model weights go to an ignored `artifacts/` folder inside the
demonstration's folder.
